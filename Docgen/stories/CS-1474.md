# CS-1474: Free Form letter

Updated 2026-10-07. Status: requirement screenshots and reference letter preview reviewed; native DOCX and implementation bindings pending.

## Confirmed requirements

For a provider case the user owns, make Free Form Letter selectable under Provider → Other Communication → Print. Populate Current Date, Billing Provider Name/Address, Provider City/State/Zip Code, Patient Name, Member ID, Date of Service, Claim Number, Case Number and Patient Account Number. Include configured header/footer and user-entered Brief Description and Free Form Content. Allow Provider Name and Mailing Address verification/updates during review and use the existing print process. Create a print communication request, display confirmation and associate communication with the case. Show the specified error message on generation/send failure and permit resubmission after resolution.
