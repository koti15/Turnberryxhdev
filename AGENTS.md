# Repository guidance for AI assistants and developers

Read [PROJECT_KNOWLEDGE_BASE.md](PROJECT_KNOWLEDGE_BASE.md) before answering questions about the Turnberry XH Salesforce project.

- Navigate by functional-area README and story ID.
- Read source/evidence files before giving a definitive answer.
- Cite repository file paths and distinguish Jira requirement from tested org behavior.
- Do not infer a working Salesforce implementation merely because documentation or partial metadata exists.
- Do not silently overwrite or 'fix' source-of-truth evidence.
- Track environments and versions explicitly.
- Never fabricate Salesforce metadata names, API responses, test results, or deployment status.
- Before making a code change, identify dependencies, actual org version, acceptance criteria, and validation plan.
- Preserve existing Docgen investigation notes and use dated supersession notes.
- Avoid committing confidential customer information, PHI, credentials, or proprietary content to this public repository.
- When adding a story, follow [REFERENCE_CONVENTIONS.md](REFERENCE_CONVENTIONS.md).
